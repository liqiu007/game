# game · 极限试炼

使用 C++17、Visual Studio 和 EasyX 制作的 I Wanna 风格平台跳跃游戏。包含主页面、五关闯关模式、持续生成地图的无尽模式、积分与死亡结算；所有画面由代码绘制，无需外部美术资源。

本版本结合组员的 [JubilWanna](https://github.com/Firefly26710773/JubilWanna) 优化角色、操作和地图：短跳/长跳、离边容错、跳跃缓冲，以及五条米饭高路。上游来源、适配范围和 MIT 许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 启动

1. Visual Studio 安装“使用 C++ 的桌面开发”和 Windows SDK，并按 [EasyX 官方说明](https://easyx.cn/setup) 安装图形库。
2. 打开 `game.sln`，选择 **Debug / x64**，按 F5 或 Ctrl+F5。
3. 主页面选择“开始游戏”或“游戏模式”，进入闯关/无尽模式。

项目在 VS 2026 使用 v145，在 VS 2022 使用 v143。当前机器已验证 VS 2026 + EasyX 26.10.25 的 Debug/Release x64；VS 2022、Win32 配置尚未实机验证。

默认从 `$(VCInstallDir)Auxiliary\VS` 查找 EasyX；自定义安装可用 `/p:EasyXRoot="目录"`。目录内应有 `include/graphics.h` 和 `lib/x64/EasyXw.lib`。输出位于 `bin/x64/Debug/game.exe`、`bin/x64/Release/game.exe`。Release 使用静态 C++ 运行时。

## 主页面与模式

- **开始游戏 / 游戏模式**：进入模式页，选择闯关或无尽。
- **闯关模式**：选关入口只在这个模式内，五关均可直接选择。通关后按 Enter 顺序进入下一关；最终关通关后 Enter 回主页面。
- **无尽模式**：向前持续生成平台和成组尖刺，没有终点，记录距离与积分；会在前方保留至少一屏半地形。
- **继续游戏**：恢复本次进程中保留的位置、积分、死亡/通关状态和机关状态。首次启动置灰；游戏中 Esc 回到主页面。暂不提供退出程序后的磁盘存档。
- **设置**：操作提示开关、三种角色颜色、60/120 FPS 绘制上限，以及全屏 / 960×640 / 1200×800 / 1440×960 显示模式，均即时生效。本次运行结束后设置恢复默认。
- **退出游戏**：结束程序。菜单可用鼠标点击，或 W/S（也支持 ↑↓）选择、D/Enter 确认、A/Esc 返回上一层。

默认以无边框全屏覆盖当前显示器，F11 可切换全屏与窗口模式，游戏进度保留。画面采用 960×640 逻辑画布居中等比例显示，宽屏两侧留边；鼠标命中同步换算，留边区域不触发按钮，物理速度和跳跃高度不随显示模式或绘制帧率改变。窗口档尺寸超过显示器工作区时会保持 3:2 比例适配到屏幕内。

## 五个关卡

| 关卡 | 背景 | 专属机制 |
| --- | --- | --- |
| 1. 小试牛刀 | 青翠山谷、草沿石台、太阳和云层 | 成组伸缩尖刺、倒挂尖刺、上下夹击；弹簧与固定高路教学 |
| 2. 断桥危机 | 暮色峡谷、裂纹桥面、岩壁和落日 | 坍塌平台、移动锯轮；水平移动高台与高低错落的支线 |
| 3. 敌人来袭 | 幽暗森林、苔色平台、月亮和萤火 | 巡逻敌人；定时高台与预警后落下的尖刺 |
| 4. 小心激光 | 霓虹实验室、金属平台、电路面板 | 错峰激光；垂直升降高台和周期消失平台 |
| 5. 终章：BOSS战 | 熔岩要塞、红岩石台、石柱和余烬 | 综合战斗、12 点生命 BOSS；水平/垂直移动高台和预警落刺 |

闯关地图宽 2240 像素，每关有 10 个主线平台、4 个单向高台和一枚米饭。第二关桥面更窄，各关高路的高度、运动方向和机关组合不同。绿色旗帜是本关存档点，金色门是终点；BOSS 存活时终点锁定，进入竞技场才显示血条。背景图案只用于装饰，实际危险对象有清晰的尖刺、锯轮、敌人或光柱形状。

米饭高路位于出生点上方：原地长按 W 起跳，再松开重按做二段跳，落上左侧蓝色高台；向右踩橙色弹簧，跳上后续高台。蓝色高台可以从下方穿过，移动时会带着角色一起走；紫色定时台每 4 秒循环，前三秒实体、后一秒虚线消失，顶部进度条提示剩余时间。落刺出现 `!` 和虚线后有 0.45 秒躲避时间。拿到米饭后，从最右高台向右走出并下落，可回到主线存档平台。探索可选，不是通关条件。

无尽模式使用独立星空背景；平台间隔 60 像素，高低变化固定在可跳范围，每三段配置一组尖刺。积分编号不会因生成新地形而变化。当前实现保留已生成地形，超长单局的内存和碰撞遍历开销会随路程增加。

## 游戏操作

| 按键 | 功能 |
| --- | --- |
| A / D | 左右移动 |
| W | 短按小跳、长按高跳，松开再按可二段跳 |
| S（空中按住） | 快速下落，仍会停在平台上 |
| J（可按住） | 朝最近移动方向连续射击 |
| R | 主动结算死亡；死亡后重生；通关后重玩本关 |
| Shift + R | 清除本局状态并重开当前关卡/模式 |
| P | 暂停 / 继续 |
| Enter | 死亡后重生；通关后下一关或返回主页 |
| Esc | 回主页面，冻结并保留本次游戏 |
| F11 | 切换全屏 / 窗口模式 |

敌人可从正上方踩击，侧面碰撞会死亡。BOSS 战要边跳跃躲弹边射击，12 次命中后开放出口。死亡界面显示原因和分数，支持鼠标按钮重生/重开。失去焦点自动停止模拟。

离开平台后约 0.1 秒内仍可起跳并保留二段跳；没有剩余跳跃时，落地前约 0.12 秒按下 W 会缓存并在落地后起跳。弹簧自动弹射并提供一次空中跳跃。鲸鱼娘使用内嵌像素图集，包含待机呼吸、两帧跑步、起跳、下落及起落形变，可切换深海蓝、海盐青、暮光紫配色。碰撞盒仍为 24×28，头发、鲸鱼尾和头饰不额外扩大受伤区域。

## 陷阱与积分

相邻地面尖刺自动分组：底座高度相差不超过 1 像素、水平间隙不超过 4 像素时合并。角色靠近组内任意一枚至 52 像素，整组在 0.08 秒内由 24 伸长至 148 像素，保持 0.75 秒，再用 0.35 秒缩回；每条命触发一次，重生复位。可在安全位置引诱，再等缩回通过。

紫色倒挂尖刺固定朝下；橙色夹击上排与关联的地面组共用进度，向下伸长至 120 像素，与下排一起闭合。绘制和碰撞共用动态尺寸。断桥、敌人、BOSS、机关在重生时恢复；计分记录保留，重开才清除。

- 每枚地面尖刺、普通倒挂尖刺 100 分，单个敌人 200 分，BOSS 1000 分。
- 夹击上下两侧按关联地面尖刺合并计分，不重复奖励。
- 闯关主线平台分值依次为 150、200、250、200、250、300、300、300、350；第一关主线全奖励为 3400 分。
- 每关米饭额外奖励 500 分，死亡保留收集状态；重开本关清除。高台本身不重复加分，探索奖励以米饭为准。
- 无尽模式每个平台 100 分，每枚尖刺 100 分。
- 同一障碍本局只奖励一次；死亡保留积分，重开清零，切换关卡开始新一局积分。
- 锯轮、激光和坍塌机制本身不单独加分，以通过的平台奖励为准。

## 编译与验证

在 Visual Studio Developer PowerShell 中，从仓库目录执行：

```powershell
msbuild game.sln /m /p:Configuration=Debug /p:Platform=x64
./bin/x64/Debug/game.exe --self-test
msbuild game.sln /m /p:Configuration=Release /p:Platform=x64
./bin/x64/Release/game.exe --self-test
./bin/x64/Release/game.exe --menu-smoke-test
./bin/x64/Release/game.exe --window-smoke-test
./bin/x64/Release/game.exe --adventure-smoke-test
```

`--self-test` 无需窗口，验证五关完整真实路线（含满血 BOSS）、12 段无尽路线、动态生成的计分编号、菜单与设置、激光开关、敌人射击/踩击、断桥坍塌、尖刺同步、死亡冻结与重生。找路线时只改变等待和输入时机，不关闭机关或修改生命。

联合版本还测试五条实际米饭路线：从出生点二段跳上高台、踩弹簧、经过活动机关、收集米饭，再安全回到主线；验证死亡保留、重开清除和奖励防刷。独立物理测试覆盖短按/长按跳跃、离边容错、跳跃缓存、单向平台穿越、平台携带/脱离、定时平台失效、弹簧、落刺预警与伤害。

截图预览会自动退出，图片在当前工作目录并被 Git 忽略：`--menu-smoke-test`、`--modes-smoke-test`、`--levels-smoke-test`、`--settings-smoke-test`、`--window-smoke-test`、`--smoke-test`、`--bridge-smoke-test`、`--enemies-smoke-test`、`--lasers-smoke-test`、`--boss-smoke-test`、`--endless-smoke-test`、`--death-smoke-test`、`--spike-smoke-test`、`--traps-smoke-test`、`--map-smoke-test`。

`--adventure-smoke-test` 展示第五关高路的鲸鱼娘、移动平台、米饭与真实落刺预警。

自测还覆盖 WASD 映射、按住 W 不连跳、S 快速下落和落地碰撞，以及横屏/竖屏下的比例、坐标换算与死亡按钮命中。窗口预览从全屏切换三档窗口尺寸，再回到全屏，逐次核验客户区大小、全屏边界与无标题栏样式，最终保存全屏截图。每次完成修改后按 `AGENTS.md` 执行检查、Git 提交、推送和远程核验。


## 跳跃与死亡反馈

实际起跳（含二段跳、离边容错及落地缓存起跳）播放合成上扬音效；无剩余跳跃次数时不播放。死亡只触发一次低沉音效与 48 枚血滴喷溅，血滴受重力影响并在约 1.34 秒内消失。结算面板延迟 0.55 秒显示，Enter / R 仍可立即重生，重生会清空血滴。音效在内存中生成 PCM WAV，由 Windows winmm 异步播放，无需下载音频资源；无可用音频设备时游戏继续运行。

角色与米饭图集根据用户提供的参考图及确认的预览制作，嵌入 `src/CharacterSprites.h`，无需外部素材路径。当前版本没有独立金币系统，原星羽收集物改为米饭，保留每关 500 分、死亡保留和重开清除的规则。

## AI 像素角色与 Windows 打包

在设置 → 选择角色中循环选择鲸鱼娘三种配色、Claude、GPT、Grok。三位 AI 娘参考 ZipZipPipe 系列设定并按用户确认的新版预览绘制：Claude 橙发抱书少女、GPT 白龙娘、Grok 金发黑金战斧少女，具有待机、奔跑与跳跃图像，支持朝向镜像、呼吸、跑动和起落形变，不代表官方角色。全部角色共享物理规则与米饭收集系统。

Windows 安装 Visual Studio C++ 桌面开发工作负载及 EasyX 后，在 PowerShell 执行 `./build-release.ps1`；自定义 EasyX 目录时执行 `./build-release.ps1 -EasyXRoot C:\EasyX`。成功编译并通过自测后输出 `dist/game.exe` 与 `dist/game-windows-x64.zip`。当前 Linux 环境尚未生成或验证 Windows 可执行文件。
